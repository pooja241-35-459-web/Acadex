### 📌 Project Overview
Acadex is a FastAPI-based faculty portal designed to track course performance, manage student enrollments, record marks, and visualize risk metrics with interactive charts.

### 🚀 Tech Stack
- **Backend:** FastAPI, SQLite, SQLAlchemy, Uvicorn
- **Frontend:** Jinja2 Templates, HTML5/CSS, Chart.js
- **Auth:** JWT Token Authentication
